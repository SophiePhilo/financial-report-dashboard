# Source Acquisition

Use this reference when the user provides a company name or ticker but does not provide the earnings source directly.

## Source priority

Prefer first-party locations in this order:

1. The company's investor-relations website.
2. A first-party regulatory filing system, such as SEC EDGAR or the equivalent market regulator.
3. An official exchange disclosure system.
4. A reputable secondary source only when first-party sources are unavailable.

Treat investor presentations as supporting sources unless they are the most complete official disclosure available.

## Confirm the report before use

Before downloading or extracting data, verify:

- company name;
- ticker when applicable;
- fiscal year and quarter;
- publication date;
- report type;
- whether the document contains the financial statements or disclosures needed for the dashboard.

Distinguish between earnings releases, financial supplements, regulatory filings, annual reports, and investor presentations. Do not substitute an investor presentation for a fuller financial source when a more complete first-party report is available.

## Selecting the latest report

Interpret "latest" using the reporting period and publication date, not the filename or search-result order alone.

Prefer the most recently published report that represents the latest completed reporting period relevant to the user's request.

If multiple first-party documents cover the same reporting period, prefer the source with the most complete financial statements and reconciliation detail. Use other official documents as supporting sources when useful.

## Download and provenance

When the selected source is remote:

- download and preserve the original document locally;
- record the source URL;
- record the document title;
- record the reporting period;
- record the publication date;
- record the retrieval date.

Do not overwrite unrelated files in the requested output directory.

## Verification

If the selected document is a PDF, preserve the original PDF even when a Markdown or text representation is created.

The downloaded first-party source remains the authoritative record for resolving discrepancies in extracted values, labels, dates, units, and table structure.
